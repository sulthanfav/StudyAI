# StudyAI agent assets

This directory contains project-scoped agent assets that may be shared across compatible coding agents.

- `skills/` contains discoverable portable Agent Skills. OpenSpec-generated skills and reviewed third-party skills live here.
- `rules/` is a project inventory for supplemental rule notes. The authoritative Codex project rules remain in the root `AGENTS.md`.
- `roles/` is a project inventory for role designs. No custom role is active. Native Codex agent definitions, if later approved, use `.codex/agents/*.toml` rather than this inventory folder.

Third-party assets are pinned and recorded in `docs/plans/CODEX_SKILLS_SETUP.md`. They are subordinate to `AGENTS.md`, the Final PRD, the approved Core Architecture, and the documentation authority order in `docs/INDEX.md`.

No project-level lifecycle hooks are installed here.
